# 07. 화면 유형 카탈로그

> 최종 수정일: 2026-11-24
> 코드 위치: `packages/shared/catalog/layouts`, 렌더러 `apps/web/src/renderer/layouts`

과제 화면은 아래 12가지 유형 중 하나입니다. 각 유형의 `data` 형식은 [04](04_assignment-schema.md#mockup), 소요 기간은 [05](05_assignment-rules.md#예상-소요-기간), 컨트롤 키 → 실제 이름은 [06](06_frameworks.md#컨트롤-이름-표)을 봅니다.

## 요약

| ID | 이름 | 난이도 | 샘플 업무 (fixtures) |
|---|---|---|---|
| `form` | 입력 폼 + 미리보기 | 초급 | 교육 신청서, 비품 대여 신청서 |
| `calc` | 계산기형 도구 | 초급 | 출장비 계산기, 연차 계산기 |
| `todo` | 체크리스트 | 초급 | 오늘의 업무 체크리스트 |
| `settings` | 탭 설정 화면 | 초급 | 개인 환경설정 |
| `wizard` | 단계형 마법사 | 초급 | 입사 서류 제출 |
| `lookup` | 검색 + 상세 조회 | 초급 | 사내 연락처 |
| `gridForm` | 그리드 + 하단 상세 폼 | 중급 | IT 비품 관리 |
| `masterDetail` | 마스터-디테일 (좌우 분할) | 중급 | 협력업체, 공지사항 |
| `kanban` | 칸반 보드 | 중급 | 고객 문의(VOC), 출장비 승인 |

| `dashboard` | 대시보드 (요약 + 목록) | 중급 | 자재 입출고 현황 |
| `treeGrid` | 트리 + 그리드 | 중급 | 사내 도서 대여 |

각 유형 설명의 표기:
- **구성**: 화면에 그려지는 영역 (위→아래, 왼→오른)
- **컨트롤 키**: "필수 사용 컨트롤" 배지에 들어가는 키
- **필수 동작**: 요구사항과 예시 화면에 반드시 들어가는 동작
- **선택 기능**: 이 화면 유형에서 가산점으로 돌리는 기능 ([05의 원칙](05_assignment-rules.md#필수선택-기능-원칙))
- **주석 핀**: [컨트롤 이름]을 켰을 때 번호가 붙는 영역

## 초급

### form — 입력 폼 + 미리보기
- **학습 목표**: 입력 컨트롤 종류별로 값 읽기, 값 변경 처리, 기본 입력 검증
- **구성**: 왼쪽 입력 그룹(57%) | 오른쪽 "입력 내용 미리보기" 그룹 + 완료 메시지 상자 / 아래 [초기화][제출]
- **컨트롤 키**: window, group, text, combo, radio, check, date, num, result, button
- **필수 동작**: 입력 즉시 미리보기 반영, 제출 시 필수값 검증 후 완료 메시지
- **선택 기능**: 글자 수 실시간 표시, 내용 복사
- **주석 핀**: 입력 그룹, 텍스트, 콤보, 라디오, 체크, 날짜, 숫자, 미리보기, 버튼

### calc — 계산기형 도구
- **학습 목표**: 숫자 입력과 형 변환, 조건별 계산, 결과 포맷팅
- **구성**: 왼쪽 "입력 조건" 그룹 + 전체 너비 [계산하기] | 오른쪽 결과 카드(큰 숫자, 세부 내역 표, 참고 문구)
- **컨트롤 키**: window, group, combo, num, date, radio, check, slider, button, result
- **필수 동작**: 계산 버튼으로 합계·세부 내역 표시, 천 단위 구분 기호
- **선택 기능**: 조건 변경 시 이전 결과 흐리게, 내역 복사
- **주석 핀**: 입력 그룹, 콤보, 날짜, 숫자, 라디오, 체크, 슬라이더, 계산 버튼, 결과

### todo — 체크리스트
- **학습 목표**: 컬렉션 다루기, 목록 갱신, 체크 상태 처리
- **구성**: 입력란 + 우선순위 콤보 + [추가] / 필터 라디오(전체·진행 중·완료) / 체크 목록 / 완료 수·진행률 + [완료 항목 지우기][선택 삭제]
- **컨트롤 키**: window, text, combo, button, radio, checklist, progress
- **필수 동작**: 추가, 체크 시 취소선·진행률 갱신, 필터, 삭제
- **선택 기능**: 드래그로 순서 변경, 마감 시간 강조
- **주석 핀**: 입력, 우선순위, 추가, 필터, 목록(클릭), 진행률, 삭제 버튼
- **예시 화면 상호작용**: 목록 항목 클릭 → 선택

### settings — 탭 설정 화면
- **학습 목표**: 탭 컨트롤, 설정값 보관과 되돌리기, 버튼 활성/비활성
- **구성**: 탭(3개) + 탭별 설정 항목 / [기본값 복원] … [취소][적용][확인]
- **컨트롤 키**: window, tabs, combo, radio, check, slider, text, button
- **필수 동작**: 탭 전환 시 값 유지, 적용·확인·취소 구분, 변경 없으면 [적용] 비활성
- **선택 기능**: 설정 파일 저장·불러오기, 미리보기 문구
- **주석 핀**: 탭, 콤보, 라디오, 체크, 슬라이더, 텍스트, 버튼
- **예시 화면 상호작용**: 탭 클릭 → 탭 전환 (기본 첫 탭)

### wizard — 단계형 마법사
- **학습 목표**: 현재 단계 상태 관리, 단계별 검증, 버튼 활성화 조건
- **구성**: 단계 표시(원 + 연결선) / "N단계 · 이름" 그룹 / 진행률 + [이전][다음 또는 제출]
- **컨트롤 키**: window, steps, group, text, combo, date, radio, check, progress, button
- **필수 동작**: 다음은 검증 후 이동, 이전은 값 유지, 마지막 단계 요약, 확인 체크 전 제출 비활성
- **선택 기능**: 완료한 단계 바로 이동, 임시 저장
- **주석 핀**: 단계 표시, 입력 그룹, 텍스트, 콤보, 날짜, 라디오, 체크, 진행률, 버튼
- **예시 화면 상호작용**: 단계 원·[이전]·[다음] 클릭 → 단계 이동 (기본 2단계)

### lookup — 검색 + 상세 조회
- **학습 목표**: 목록 필터링, 선택 이벤트로 상세 표시, 조회 전용 화면
- **구성**: 왼쪽 검색란·부서 콤보·인원 수·두 줄 목록 | 오른쪽 "상세 정보"(이니셜 원, 이름, 항목 표, [메신저 보내기][이메일 복사])
- **컨트롤 키**: window, text, combo, list, group, button
- **필수 동작**: 입력 즉시 필터, 선택 시 상세 표시, 결과 없음 안내
- **선택 기능**: 검색어 강조, 최근 본 목록
- **주석 핀**: 검색, 부서 필터, 목록(클릭), 상세, 버튼
- **예시 화면 상호작용**: 목록 클릭 → 상세 변경

## 중급

모든 중급 유형은 표 데이터([04의 TableData](04_assignment-schema.md#중급-화면-유형의-data))를 씁니다. 상태 열은 데스크톱에서 색 점 + 글자, 웹에서 둥근 배지로 그립니다.

### gridForm — 그리드 + 하단 상세 폼
- **학습 목표**: 검색 조건 → 목록 → 상세 폼으로 이어지는 기본 CRUD 흐름과 DB 연동
- **구성**: "검색 조건" 그룹(콤보·텍스트·기간 2개·[조회]) / 그리드 / 상세 정보 그룹(3열 폼) / [엑셀 내보내기] … [신규][등록][수정][삭제]
- **컨트롤 키**: window, menu, group, combo, date, text, grid, detail, button, status
- **필수 동작**: 행 선택 시 상세 폼 채움, 신규·등록·수정·삭제
- **선택 기능**: 정렬·페이징, 엑셀 내보내기
- **주석 핀**: 검색 그룹, 콤보, 기간, 그리드(클릭), 상세 폼, 버튼

### masterDetail — 마스터-디테일 (좌우 분할)
- **학습 목표**: 좌우 분할 레이아웃, 목록과 상세 탭의 선택 동기화, 하위 데이터 조회
- **구성**: 왼쪽 검색란 + 두 줄 목록(상태 점) | 분할선 | 오른쪽 이름·상태 배지 / 탭(기본 정보 폼 2열 + 하위 목록 표) / [신규][저장][삭제]
- **컨트롤 키**: window, text, list, split, tabs, detail, grid, button
- **필수 동작**: 목록 선택 → 상세·하위 목록 갱신, 저장 후 목록 즉시 갱신
- **선택 기능**: 스플리터로 크기 조절, 엑셀 내보내기
- **주석 핀**: 검색, 목록(클릭), 분할선, 탭, 상세 폼, 하위 목록, 버튼

### kanban — 칸반 보드
- **학습 목표**: 상태별 그룹핑, 카드 선택, 상태 이동, 상세 패널 동기화
- **구성**: 검색란 + 담당자 콤보 … [+ 등록] / 상태 열 3개(헤더에 건수, 카드) | 오른쪽 "선택 항목" 패널(입력란, [다음 단계로 이동], [수정][삭제])
- **컨트롤 키**: window, text, combo, button, kanban, card, group
- **필수 동작**: 카드 선택 → 상세 표시, **[다음 단계로 이동] 버튼으로 상태 변경**
- **선택 기능**: 드래그 앤 드롭, 오래된 카드 강조, 열 합계
- **주석 핀**: 검색, 필터, 등록, 상태 열, 카드(클릭), 다음 단계 버튼, 상세 패널
- **예시 화면 표시**: 가운데 열 아래 "끌어 놓기 (선택 기능)" 점선 영역

### calendar — 주간 캘린더 + 대화상자
- **학습 목표**: 시간 → 좌표 배치 계산, 모달 대화상자로 등록·수정
- **구성**: [‹][›][오늘] 기간 제목 … 회의실 콤보, [+ 새 예약] / 주간 시간표(9~18시, 월~금, 오늘 열 강조) / 오른쪽 위에 "예약 수정" 대화상자
- **컨트롤 키**: window, button, combo, calendar, card, dialog, text, date
- **필수 동작**: 예약 블록 표시, 블록 클릭 → 수정 대화상자, [새 예약] → 등록 대화상자, 중복 시간 차단
- **선택 기능**: 블록 드래그로 시간 변경, 빈 칸 더블클릭 등록, 현재 시각 선
- **주석 핀**: 주 이동, 회의실 필터, 새 예약, 시간표, 예약 블록(클릭), 대화상자
- **렌더러 메모**: 웹 스킨은 대화상자 뒤 시간표를 어둡게 덮음

### dashboard — 대시보드 (요약 + 목록)
- **학습 목표**: 집계 쿼리, 요약 카드, 수치와 목록 동기화
- **구성**: 조회 기간·분류·[조회] … [+ 등록] / 요약 카드 4개 / 차트 카드 | 비율 카드 / 최근 내역 그리드
- **컨트롤 키**: window, date, combo, button, card, chart, progress, grid
- **필수 동작**: 같은 조회 조건으로 요약 카드와 최근 내역 갱신, 등록 후 수치 재계산
- **선택 기능**: 막대 차트, 비율 그래프, 전월 대비 증감률 (차트 라이브러리 사용 가능)
- **주석 핀**: 조회 기간, 등록, 요약 카드, 차트(선택), 비율(선택), 그리드(클릭)
- **예시 화면 표시**: 차트·비율 카드에 "선택" 배지

### treeGrid — 트리 + 그리드
- **학습 목표**: 계층 데이터 표시, 모달 등록 대화상자, 상태 변경 처리
- **구성**: 왼쪽 분류 트리(건수) | 오른쪽 분류 제목·검색·[등록][수정][삭제] / 그리드 / "선택: …" + [대여 처리][반납 처리]
- **컨트롤 키**: window, tree, text, button, grid, ctx, dialog
- **필수 동작**: 트리 선택 → 하위 분류까지 목록 표시, [등록]은 대화상자, **[대여 처리]·[반납 처리] 버튼** (상태에 따라 비활성)
- **선택 기능**: 우클릭 메뉴, 연체 행 강조, 트리 펼침 상태 기억
- **주석 핀**: 트리, 검색, 버튼, 그리드(클릭), 대여·반납 버튼, 우클릭 메뉴(선택)
